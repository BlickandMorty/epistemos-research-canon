# Status boundary

This repository is a public research archive. It contains recovered claims at different maturity levels and should not be used as evidence that every described component is implemented.

Use the standalone repositories for runnable code. Use `epistemos-formal-primitives/PROOF_STATUS.md` for the exact theorem/candidate split. Use the source anchors in `RECOVERY_MATRIX.md` when tracing an idea back into Epistemos history.

The HTML explainer includes historical labels such as floor, gated, partial, research, and future. Those labels are part of the recovered record and should be read literally.
